# Monitor Script

Скрипт мониторинга сервера с алертами в Telegram.

## Что делает

- Собирает метрики системы через `psutil`: загрузка CPU, использование RAM, свободное место на диске.
- Проверяет доступность HTTP-сервисов по списку URL с таймаутом 5 секунд.
- При превышении порогов или недоступности сервиса отправляет алерт в Telegram.
- Логирует работу в `monitor.log` с ротацией по размеру (при превышении 1 МБ лог архивируется в `monitor.log.old`).
- Запускается автоматически через Планировщик заданий Windows каждые 5 минут.

## Стек

- Python 3
- `psutil` - сбор системных метрик
- `requests` - HTTP-запросы и отправка сообщений в Telegram
- `python-dotenv` - хранение токена бота в `.env`-файле
- Telegram Bot API

## Установка

1. Клонировать репозиторий:
   ```
   git clone <URL_РЕПОЗИТОРИЯ>
   cd monitor
   ```

2. Установить зависимости:
   ```
   pip install psutil requests python-dotenv
   ```

3. Создать файл `.env` рядом с `monitor.py` и заполнить:
   ```
   TELEGRAM_TOKEN=твой_токен_бота
   TELEGRAM_CHAT_ID=твой_chat_id
   ```

   - Токен получается у [@BotFather](https://t.me/BotFather) командой `/newbot`.
   - `chat_id` можно узнать через `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после отправки сообщения боту.

4. Запустить:
   ```
   python monitor.py
   ```

## Автозапуск

В проекте есть `run_monitor.bat` — он запускает скрипт и перенаправляет вывод в `monitor.log` с ротацией.

Для автоматического запуска используется Планировщик заданий Windows:

1. Открыть `taskschd.msc`.
2. Создать простую задачу с триггером «Ежедневно».
3. В свойствах задачи выставить повтор каждые 5 минут, в течение неограниченного времени.
4. В действии указать путь к `run_monitor.bat`.

## Конфигурация

Пороги и список сервисов задаются в начале `monitor.py`:

```python
THRESHOLDS = {
    "cpu": 90,
    "ram": 85,
    "disk": 90,
}

SERVICES = [
    "https://ya.ru",
    "https://github.com",
]
```

- `THRESHOLDS` — пороги в процентах, при превышении которых отправляется алерт.
- `SERVICES` — список URL, доступность которых проверяется.

## Как это работает

1. Скрипт собирает метрики CPU, RAM и диска через `psutil`.
2. Сравнивает их с порогами из `THRESHOLDS`.
3. Проверяет доступность каждого URL из `SERVICES` через HTTP GET.
4. Если есть проблемы — формирует сообщение и отправляет его в Telegram.
5. Пишет результат работы в `monitor.log`.

## Безопасность

Токен бота хранится в `.env` и **не попадает в репозиторий** — файл добавлен в `.gitignore`.
